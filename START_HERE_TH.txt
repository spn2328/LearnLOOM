ไฟล์เว็บไซต์ LearnLOOM ฉบับครบชุด
ห้องเก็บสารไร้ป้าย คดีที่ตาเปล่าตัดสินไม่ได้

เริ่มอ่านไฟล์นี้ก่อนเปิดโครงการ

สิ่งที่รวมอยู่ในชุดนี้
- โค้ดหน้าเว็บและส่วนติดต่อผู้ใช้ทั้งหมด
- เรื่องเล่าแบบแตะเพื่ออ่านต่อ และคลังคำถามหลัก 36 ข้อพร้อมตัวเลือก เหตุผล และเกณฑ์ตรวจ
- บทเรียน กิจกรรม แบบจำลองโมเลกุล 3D และภาพ 2D สำรอง
- กิจกรรมพัก My Skills ประวัติการเรียน และคู่มือในเว็บ
- ส่วนครู ห้องเรียน สนทนา บันทึกความคืบหน้า และส่งออก Excel
- รูปประกอบทั้ง 3 ภาพ ฟอนต์ภาษาไทย และไอคอนเว็บ
- โครงสร้างฐานข้อมูลและไฟล์สร้างตารางในโฟลเดอร์ drizzle
- รายการแพ็กเกจและไฟล์ล็อกเวอร์ชันสำหรับติดตั้งซ้ำ
- เอกสารถอดคำถามทุกข้อใน docs/LearnLOOM_All_Questions.txt

วิธีเปิดสำหรับผู้พัฒนาหรือผู้ที่มีพื้นฐานติดตั้งเว็บ
1. แตก ZIP แล้วเข้าโฟลเดอร์ LearnLOOM
2. เตรียม Node.js ตามเงื่อนไขใน package.json คือเวอร์ชัน 22.13.0 ขึ้นไป
3. เปิด Terminal ในโฟลเดอร์ LearnLOOM แล้วติดตั้ง pnpm เวอร์ชันที่โครงการกำหนด

   npm install --global pnpm@11.25.0

4. ติดตั้งแพ็กเกจตามไฟล์ล็อก

   pnpm install --frozen-lockfile

5. สร้างไฟล์เว็บและการตั้งค่าฐานข้อมูลสำหรับรันบนเครื่อง

   pnpm run build

6. สร้างตารางในฐานข้อมูลจำลองบนเครื่อง ก่อนเข้าใช้งานครั้งแรก

   pnpm exec wrangler d1 execute DB --local --persist-to .wrangler/state --config dist/server/wrangler.json --file drizzle/0000_massive_vampiro.sql

7. เปิดเว็บในโหมดพัฒนา

   pnpm run dev

8. เปิดที่อยู่ที่ Terminal แสดง โดยโหมดปกติของโครงการกำหนดพอร์ต 5173
   เช่น http://localhost:5173

โครงการนี้มีส่วนเซิร์ฟเวอร์และฐานข้อมูล จึงต้องรันตามขั้นตอนด้านบน
การเปิดไฟล์หน้าเว็บด้วยการดับเบิ้ลคลิกอย่างเดียวจะไม่เริ่มระบบครบทั้งหมด
ถ้ารันคำสั่งฐานข้อมูลครั้งที่สองแล้วแจ้งว่าตารางมีอยู่แล้ว ให้ใช้ฐานข้อมูลเดิมต่อได้

ตำแหน่งไฟล์สำคัญ
- app/page.tsx และ app/layout.tsx: จุดเริ่มต้นของหน้าเว็บ
- components/learnloom-app.tsx: หน้าจอหลักและลำดับการเรียน
- components/lesson.tsx: บทเรียนและกิจกรรม
- components/molecule.tsx: แบบจำลองโมเลกุล 3D และ 2D
- components/reports.tsx: สรุปผลผู้เรียนและพื้นที่ครู
- components/support.tsx: สนทนาและคู่มือ
- lib/content.ts: เรื่องเล่า คำถาม ตัวเลือก เฉลย และบทช่วย
- lib/learning.ts: เกณฑ์และการประมวลผลความเข้าใจ
- lib/use-learning.ts: การบันทึกและการซิงก์ข้อมูล
- app/api: ส่วนรับส่งข้อมูลจากเซิร์ฟเวอร์
- db และ drizzle: โครงสร้างและไฟล์สร้างฐานข้อมูล
- public/images: ภาพประกอบทั้งหมด
- public/fonts: ฟอนต์ภาษาไทย
- public/sw.js: การเตรียมเนื้อหาสำหรับออฟไลน์
- .openai/hosting.json: การตั้งค่าการเผยแพร่ของเว็บเดิม
- README.md: รายละเอียดความสามารถและข้อจำกัดของเวอร์ชันนี้
- SOURCE_MANIFEST.json: รายการไฟล์ต้นฉบับและค่า SHA256 สำหรับตรวจสอบความครบถ้วน

เรื่องฐานข้อมูลและการยืนยันบัญชี
ชุดนี้มีโค้ดและโครงสร้างฐานข้อมูลครบ แต่ข้อมูลบัญชี ข้อความ และผลการเรียนที่บันทึกบนคลาวด์อยู่ในระบบฐานข้อมูลของเว็บเดิม
ขั้นตอนรันบนเครื่องจะสร้างฐานข้อมูลใหม่ที่ยังไม่มีข้อมูลผู้เรียน
การยืนยันบัญชี ChatGPT บนเว็บเผยแพร่ผูกกับระบบ Sites ส่วนสภาพแวดล้อมพัฒนามีการจำลองการยืนยันบัญชี
หากนำไปเผยแพร่ด้วยผู้ให้บริการอื่น ผู้พัฒนาต้องตั้งค่าฐานข้อมูลและปรับระบบยืนยันบัญชีให้เหมาะสม

ไฟล์โครงการคงตามเวอร์ชันเว็บที่สร้างและเผยแพร่ไว้
ผังเส้นทางคำถามที่เสนอภายหลังยังเป็นแนวทางออกแบบ ไม่ได้ถูกแทนที่ลงในโค้ดเว็บชุดนี้
วิดีโอคู่มือและการอัปเดต Excel บนคลาวด์อัตโนมัติยังไม่ได้เชื่อมในเวอร์ชันนี้

แพ็กเกจที่ติดตั้งได้ใหม่และข้อมูลชั่วคราวบนเครื่อง เช่น node_modules, .git, ไฟล์แคช และฐานข้อมูลทดสอบ ไม่ได้รวมไว้ใน ZIP
