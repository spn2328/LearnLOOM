# วิธีใส่ภาพ / วิดีโอ / แอนิเมชัน

**วางไฟล์ในโฟลเดอร์นี้ (`media/`) แล้วตั้งชื่อตาม "รหัสตำแหน่ง" ภาพจะขึ้นในหน้านั้นเองตอน build โดยไม่ต้องแก้โค้ด**

## รูปแบบชื่อไฟล์

```
<รหัสตำแหน่ง>.<นามสกุล>              ภาพ/วิดีโอเดียว        ep01-s01.mp4
<รหัสตำแหน่ง>-<ลำดับ>.<นามสกุล>       หลายไฟล์เรียงลำดับ     ep01-s08-1.webp, ep01-s08-2.mp4
<รหัสตำแหน่ง>.loop.<นามสกุล>         แอนิเมชันวนซ้ำ (เล่นเอง ไม่มีเสียง)  ep01-l01.loop.mp4
```

- ใช้ตัวพิมพ์เล็ก ห้ามมีเว้นวรรคหรือภาษาไทยในชื่อไฟล์
- ภาพ: `.webp` (แนะนำ, ไฟล์เล็ก) `.png` `.jpg` `.gif` `.avif` `.svg`
- วิดีโอ: `.mp4` (แนะนำ, เล่นได้ทุกเครื่อง) `.webm` `.mov` (`.mov` อาจไม่เล่นบน Chrome/Android — แปลงเป็น mp4 ก่อนดีที่สุด)
- วิดีโอปกติมีปุ่มเล่น/หยุด; ถ้าใส่ `.loop` จะเล่นวนเองแบบไม่มีเสียงเหมือน GIF (ถ้าเครื่องผู้ใช้ตั้ง "ลดการเคลื่อนไหว" จะไม่เล่นเอง)
- แนะนำขนาดภาพไม่เกิน ~500KB ต่อไฟล์ (กว้าง ~1600px) เพื่อให้เปิดเร็วบน Wi-Fi โรงเรียน
