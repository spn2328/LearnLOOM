# เสียงอ่านภาษาไทย (AI)

เว็บอ่านออกเสียงด้วยไฟล์ MP3 ที่สร้างล่วงหน้า (`public/voice/`, ~894 ไฟล์ ~22 MB) ด้วยเสียง neural ภาษาไทยของ Microsoft
(`th-TH-PremwadeeNeural`; บทพูดของ เจฟ / เฮียศักดิ์ / ชาวบ้าน ใช้ `th-TH-NiwatNeural`)
ทุกเครื่องจึงได้ยินเสียงเดียวกัน และเปิดฟังออฟไลน์ได้หลังกด "เตรียมชุดออฟไลน์"
ข้อความที่ไม่มีไฟล์เสียง (เช่น ชื่อเล่นที่ผู้เรียนพิมพ์) จะใช้เสียงของเครื่องแทน

## สร้าง/อัปเดตไฟล์เสียง
รัน `pnpm gen:voice` — สร้างเฉพาะข้อความใหม่/ที่เปลี่ยน (ไฟล์เดิมเก็บไว้) แล้ว commit `public/voice/`
`pnpm gen:voice -- --dry-run` ดูจำนวนตัวอักษรที่จะส่งโดยไม่เรียกบริการ

### เครื่องสร้างเสียง (เลือกอัตโนมัติ)
- **ค่าเริ่มต้น (ไม่ต้องมีคีย์):** บริการ "อ่านออกเสียง" ของ Microsoft Edge ผ่านแพ็กเกจ `msedge-tts`
  — ไฟล์ชุดปัจจุบัน (3 พ.ย.) สร้างด้วยวิธีนี้ **ไม่ใช่ API ทางการ** อาจถูกปิดหรือเปลี่ยนเมื่อไรก็ได้ และไม่มีการรับรองเงื่อนไขการใช้งาน
  ไฟล์ที่สร้างแล้วยังใช้ได้ต่อ ถ้าบริการหยุดจะกระทบแค่การสร้างไฟล์ใหม่
- **Azure AI Speech (ทางการ):** ถ้า `.env.local` (อยู่ใน .gitignore ห้าม commit) มี
  ```
  AZURE_SPEECH_KEY=คีย์จริง
  AZURE_SPEECH_REGION=southeastasia
  ```
  สคริปต์จะใช้ Azure แทน (Free F0 = 500,000 ตัวอักษร/เดือน; ทั้งบทใช้ราว 33,000) — ถ้าต้องการเปลี่ยนไฟล์ทั้งหมดเป็นของ Azure ให้ลบ `public/voice/` แล้วรันใหม่
  `--edge` บังคับใช้ Edge แม้มีคีย์

## ข้อมูลที่ส่งออกนอกเครื่อง
ส่งเฉพาะข้อความบทเรียนจากไฟล์ source ไป Microsoft ตอนรันสคริปต์เท่านั้น ไม่ส่งข้อมูลผู้เรียน และหน้าเว็บไม่เรียกบริการเสียงเลย

## ทางเทคนิค
- `scripts/voice-texts.mjs` เก็บข้อความไทยทั้งหมด (string + JSX text ใน `features/fake-hero`) และ `voiceKey()`
- `features/fake-hero/voice.ts` ต้องมี `norm()`/`voiceKey()` ตรงกัน (ตรวจใน `scripts/test-fake-hero.mjs` พร้อมตรวจว่าโจทย์/ตัวเลือกทุกข้อถูกเก็บ)
- `speak(parts)` ใน `vark.ts` เล่นทีละส่วน: มีไฟล์ → MP3, ไม่มี/โหลดไม่ได้ → เสียงเครื่อง
- สิ่งที่เสียงอ่าน: ตัวห้อย → ตัวเลข (CH₃ → CH3), – = ≡ → "พันธะเดี่ยว/คู่/สาม"
