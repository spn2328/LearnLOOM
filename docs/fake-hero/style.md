## 2. ตัวอักษร
- หัวเรื่อง ปุ่ม เมนู ป้าย: **Itim** (Google Fonts) สำรองเป็น Noto Sans Thai
- เนื้อความ: **Noto Sans Thai** 400/600
- ระยะบรรทัด: ทั่วไป 1.5, ย่อหน้า/รายการ 1.7, หัวเรื่อง 1.3 (`text-wrap: balance`) ความกว้างย่อหน้าไม่เกิน 68ch
- ห้ามเปลี่ยนฟอนต์ (กฎ lf-ui-guard)

## 3. พื้นหลัง
- **ทุกหน้า:** ภาพลายนักสืบโทนครีม วางบนเลเยอร์ `position: fixed` + `background-size: cover` ไม่ยืดภาพ ไม่ซ้ำลาย ไม่มีรอยต่อเมื่อเลื่อน
  | ความกว้างจอ | ไฟล์ |
  |---|---|
  | ≥1600 | `/images/backgrounds/desktop-1920x1080.webp` |
  | ≤1599 | `laptop-1440x900.webp` |
  | ≤1023 แนวนอน / แนวตั้ง | `tablet-landscape-1180x820.webp` / `tablet-portrait-820x1180.webp` |
  | ≤767 / ≤410 / ≤375 แนวตั้ง | `mobile-430x932.webp` / `mobile-390x844.webp` / `mobile-360x800.webp` |
- ข้อความที่วางบนลายโดยตรงมีเงากระดาษ (`text-shadow` สีครีม) เพื่อให้อ่านชัด
- **Sidebar:** กระดาษกราฟครีม `/images/sidebar-grid.webp` ขนาด 411×411px `repeat` (ห้ามใช้ `100% 100%`) พื้นสำรอง `#FFFEFB` เส้นแบ่งขวา 2px `--dt-line`

## 4. คอมโพเนนต์

### การ์ด / แผง
`.fh-card, .gm-card, .fh-panel, .fh-scene, .fh-question, .fh-chapter, .fh-cert, [data-slot=card]` ฯลฯ
- พื้น `--dt-card` ขอบ `--dt-line`
- เงา `--dt-lift` = `0 0 0 1.5px #DCC6A0, 0 4px 0 #DCC6A0, 0 10px 22px rgba(92,64,28,.12)`
- ล็อกอยู่: พื้นทึบ `#F3ECDD` ตัวอักษร `#5A6275` รูปเป็นขาวดำ (ไม่ใช้ความโปร่ง)

### ปุ่มแบบเกม 2.5D
| ประเภท | หน้าปุ่ม | ขอบ + ขอบล่างนูน | ใช้กับ |
|---|---|---|---|
| หลัก `.primary .fh-primary .fh-play` | ไล่สี `#E8977A → #DB7C56` ตัวอักษร ink | ขอบ 2px `#A84A26` + ขอบล่าง 4px + เงาตก | ไปต่อ / เริ่ม |
| ตรวจคำตอบ `.fh-qfoot .primary` | ไล่สี `#6BB88A → #3A8F5D` ตัวอักษรขาว | `#23683F` | ส่งคำตอบ |
| รอง `.secondary .round-button` | ขาว → `#EEF0F9` | ขอบ 2px `#7285C1` ขอบล่าง `#3E4F8C` | ก่อนหน้า / ย้อนกลับ |
| ถามลูม `.fh-help` | `#FFF1F6 → #FDE3EE` | ขอบ `#E9A6C4` ขอบล่าง `#D07FA4` | ขอความช่วยเหลือ |
| Disabled | `#EEF0F3` | ขอบประ `#9AA3B5` ไม่มีเงา | ยังกดไม่ได้ |
- กด: ปุ่มจม `translateY(3px)` ขอบล่างเหลือ 1px (0.08s)
- โฟกัสคีย์บอร์ด: เส้น 3px `#3E4F8C` ห่าง 3px
- ปุ่มแตะต้องสูงอย่างน้อย 44px

### ป้ายสถานะ (Badge / Pill)
ทรงแคปซูล ขอบ 2px ขอบล่าง 3px ตัวหนา 600
- `.fh-pill` เขียว (ผ่าน/สำเร็จ) · `.fh-qtag .fh-chip` Ballpoint (รหัสคำถาม) · `.fh-chip.red` Apple · `.fh-badge` Highlight · `.fh-cert em` เทาประ (ยังไม่ได้)

### แถบความก้าวหน้า
ราง `#E6E8EE` ลึกลง (inset shadow) + ขอบ `#D3D7E0` · แถบเติม ไล่สีเขียว `#5FAE7F → #3A8F5D → #2F7C4F` มีแสงด้านบน

### ไอคอน 2.5D
- lucide: เส้น 2.5 เติมสี 18% วางบนแผ่นสีนูน
- sidebar ไล่สีตามลำดับเมนู: Ballpoint, Apple, Growth, Highlight อ่อน, Highlight, Apple
- `.cute-icon` (SVG ที่วาดแผ่นเอง) ขนาด 24px ใน sidebar, 26px ในแถบล่างมือถือ

### Sidebar
- เมนูที่ไม่เลือก: โปร่งให้เห็นลายกริด ตัวอักษร `#3D4458`
- เมนูที่เลือก: พื้น `#EEF0F9` ตัวอักษร `#3E4F8C` วงขอบใน 2px `#7285C1` ขอบล่าง 3px `#3E4F8C`
- มือถือ: ลิ้นชักใช้ลายกริดเดียวกัน

### แถบล่างมือถือ `.fh-bottom-nav`
พื้น card ขอบบน 2px line · แท็บปัจจุบันเป็นแคปซูล Ballpoint · ไอคอนบนแผ่นเหลืองอ่อน

### ลากวาง (DragSort)
- การ์ดลาก `.fh-dcard` มี ⠿ ที่มุม รองรับเมาส์ลาก + แตะเลือกแล้วแตะช่อง + คีย์บอร์ด Enter/Space
- ช่องวาง `.fh-target` เมื่อลากผ่าน: `over` ยก/ขยายเล็กน้อย, เมื่อมีการ์ดถูกเลือก: `ready` มีวงแสง

### ภาพตัวละคร / สื่อ
- โลโก้ + ลูม (red panda) `/images/loom.webp`
- ไอคอนบทบาท `/images/roles/{student,teacher,general}.webp` 40×40 `object-fit: contain`
- โมเลกุล C03 `/images/molecules/molecule_{A,B,C}.png` `object-fit: contain`
- ห้ามแก้ภาพ วิดีโอ แอนิเมชันของเนื้อเรื่องเดิม

### การเคลื่อนไหว
ทุก transition 0.08–0.15s และปิดทั้งหมดเมื่อ `prefers-reduced-motion: reduce`

## 6. กฎที่ต้องรักษา
- ห้ามเปลี่ยนข้อความ คำถาม ตัวเลือก เฉลย เนื้อเรื่อง และเนื้อหาเคมีที่ยืนยันจาก PDF
- ห้ามเปลี่ยน Layout, ฟอนต์ Itim, โครงสร้าง sidebar/การนำทาง เว้นแต่เจ้าของสั่ง
- CSS ใหม่ให้ scope เฉพาะหน้า (เช่น `.fh-q03`) และเปลี่ยนเฉพาะสี/เงา/transform
- ตรวจทุกครั้งที่ Desktop 1440, Tablet 768×1024, Mobile 375×812 ภาษาไทยต้องไม่ถูกตัด
- Contrast ≥ 4.5:1 · ปุ่มเป็น `<button>` จริง · มีโฟกัสที่มองเห็น · พื้นที่แตะ ≥ 44px
