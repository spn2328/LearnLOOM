# Prompt templates — LearnLOOM The Fake Hero

> ข้อห้ามถาวรของงานปัจจุบัน: **ห้ามเปลี่ยนหน้าตาเว็บไซต์เดิม** รวมถึงสี โทน ฟอนต์ ระยะห่าง layout ปุ่ม เมนู กรอบ และ CSS เว้นแต่จะมีคำสั่งใหม่จากเจ้าของโดยตรง; ให้แก้เนื้อหา/พฤติกรรมเฉพาะจุดที่ระบุ ตรวจ build และอัปเดต `docs/fake-hero/state.md` ทุกครั้ง. ห้ามเปลี่ยนโจทย์ ตัวเลือก เฉลยหรือคำพูดต้นฉบับที่ยืนยันแล้วโดยพลการ.

## 1. ปรับเนื้อหาเคมี
```
ทำงานบน repository spn2328/LearnLOOM และสร้าง branch แยกจาก main
ปรับเฉพาะเนื้อหา EP.[...] ฉาก [...] / Concept [...] ตามไฟล์ PDF ที่แนบ
ตำแหน่งที่ต้องแก้: [...]
ข้อความเดิม: [...]
ข้อความใหม่: [...]
รักษาเนื้อเรื่อง คำถาม ตัวเลือก เฉลยของข้ออื่นและ UI/CSS/โครงสร้างหน้าเดิมทั้งหมด ห้ามเปลี่ยน
ตรวจความถูกต้องทางเคมี จัดรายการไฟล์ที่เปลี่ยน และรัน test/typecheck/build:demo
อัปเดต docs/fake-hero/state.md แล้วเปิด PR ให้ตรวจโดยไม่ merge เอง
```

## 2. ปรับหน้าตา (เฉพาะเมื่ออนุญาตชัดเจน)
```
ให้แก้หน้าตาเฉพาะองค์ประกอบ [...] ของหน้า [...] เท่านั้น
ภาพตัวอย่าง/ไฟล์อ้างอิง: [...]
สิ่งที่ต้องคงเดิม: โทนสี ฟอนต์ ปุ่ม เมนู responsive ของหน้าอื่น และข้อความต้นฉบับ
ก่อนแก้เปรียบเทียบภาพเก่า-ใหม่; หลังแก้ตรวจ desktop/tablet/mobile
ห้ามแก้เนื้อหาเคมีหรือเส้นทาง Adaptive; อัปเดต state.md และเปิด PR
```

## 3. เพิ่มภาพและแอนิเมชันภายหลัง
```
เพิ่มภาพ/แอนิเมชันเฉพาะ Scene [...] หรือ Action [...] โดยคง UI ปัจจุบันทุกจุด
รายละเอียดภาพ ตัวละครและฉาก: [...]
ความเคลื่อนไหว: [...]
ระยะเวลา/รูปแบบไฟล์: [...]
มีภาพนิ่งทดแทน เปิดปิดการเคลื่อนไหวได้ รองรับ prefers-reduced-motion และไม่ทำให้เนื้อหาคำถามหายไป
ยังไม่เผยแพร่ไฟล์ที่ไม่มีสิทธิใช้งาน ตรวจ performance และทดสอบอุปกรณ์จริง
อัปเดต docs/fake-hero/state.md
```

## 4. เพิ่มฟังก์ชันหรือกิจกรรม
```
เพิ่มฟังก์ชัน [...] ใน EP.[...] ระหว่างขั้น [...] กับ [...]
พฤติกรรมที่คาดหวัง: [...]
กรณีตอบถูก: [...]
กรณีตอบผิดหรือเหตุผลผิด: [...]
ข้อมูลที่ต้องบันทึก: คำตอบครั้งแรก เหตุผล การช่วยเหลือ Recheck และ timestamp (เฉพาะที่จำเป็น)
รองรับการย้อนกลับและรีเฟรช ไม่บังคับวนซ้ำไม่สิ้นสุด
รักษา UI และคำถามที่ยืนยันเดิม ห้ามเปลี่ยนทั้งสองส่วน
เขียน acceptance tests, รัน build, อัปเดต state.md แล้วทำ PR
```
