# แผนพัฒนาเว็บไซต์สาธิต The Fake Hero

## เป้าหมาย
ทำเดโมบางช่วงของ EP.01 ที่ผู้ชมเล่นได้ตั้งแต่เปิดคดีถึงสรุป เพื่อแสดงว่าผู้เรียนตรวจหลักฐาน เรียนรู้ ตอบพร้อมเหตุผล และได้รับความช่วยเหลือตามคำตอบอย่างไร ไม่กล่าวว่าเรียนจบ EP.01 ทั้งหน่วยหรือพิสูจน์ผลสัมฤทธิ์

## ขอบเขต
- ทำงานจริง: ฉากเปิดคดีและ S01, บทเรียน L01, กิจกรรมจำแนก A03, Q01/Q01-E, R01 Path B สำหรับตัวอย่างที่กำหนด, RC01 และสรุปผล
- ฉาก 02 แสดงคำให้การเจฟและสมุดหลักฐานในรูปแบบสั้นโดยใช้ข้อความที่ยืนยันตามต้นฉบับ; ไม่มีการพิพากษาจากคลิป
- คำตอบอื่น: ใช้คำชี้แนะทั่วไปและให้ลองอีกครั้งหรืออธิบายก่อนดำเนินต่อ; อย่าอ้างว่าระบบวินิจฉัยสาเหตุได้แน่นอน
- แสดงหน้า Episode อื่นเป็นโครงสร้างอนาคตพร้อมสถานะยังไม่เปิด
- บันทึกเบราว์เซอร์เดียวเป็นงานควรมี หากทำและทดสอบได้; อธิบายข้อมูลอาจหายเมื่อล้างข้อมูล
- ระบบบัญชีจริง/ฐานข้อมูลกลาง/ซิงก์ข้ามเครื่อง/ออฟไลน์/เกียรติบัตร/แดชบอร์ดจริงไม่ใช่ข้อกำหนดเดโม; ถ้ามีหน้าครูให้ใช้ข้อมูลจำลองและติดป้าย
- ไม่ใช้คอยน์; VARK เป็นทางเลือกเข้าถึงสื่อ ไม่แบ่งประเภทผู้เรียนตายตัว

## Phase 0 — ทิศทาง
ตรวจแหล่งข้อมูล ช่วงสาธิต รูปแบบหน้าจอ อุปกรณ์และเวลานำเสนอ; แยกหน้าที่ทำจริงกับแนวคิดอนาคต เสร็จเมื่อกำหนดขอบเขตและคำถามค้างใน state.md

## Phase 1 — ออกแบบการเรียนรู้
ตรวจความถูกต้องของข้อความ/โมเลกุลและตัวเลือกเทียบต้นฉบับโดยไม่แก้โจทย์ ทำตาราง event/feedback และ mockup พร้อมทางกลับจากบทช่วย; เสร็จเมื่อเจ้าของตรวจ content และ flow รวมทั้งข้อความที่คงต้นฉบับ

## Phase 2 — สร้างเดโม
1. รัน baseline ของเว็บเดิมและบันทึกผล; สำรวจ demo/main.tsx, demo/use-learning.ts, components/ และ lib/ ก่อนเลือกส่วนใช้ซ้ำ
2. สร้างเส้นทางใหม่แยกจากบทเรียนเดิม เชื่อมหน้าเริ่ม → เรื่อง → A03 → Q01 → บทช่วยเมื่อเข้าเงื่อนไข → Recheck → สรุป
3. ทำภาพ/โมเลกุลแบบ 2D เป็นฐาน; การหมุน 3D และเสียงเป็นตัวเลือกเสริมหากพร้อม ไม่เป็นเงื่อนไขเล่นจบ
4. แสดงการตอบครั้งแรกแยกจากการทำหลังช่วย; ให้จบเดโมได้แม้ยังต้องทบทวน
5. หากทำ pause/resume ให้ทดสอบขอบเขตจริงและเก็บเฉพาะชื่อเล่น/ข้อมูลจำลอง

## Phase 3 — ตรวจคุณภาพเดโม
- ตรวจ S01 ผิดแล้วลองใหม่, Q01+เหตุผลถูก, Q01 ถูกแต่เหตุผล A, คำตอบแบบอื่น, RC01 ถูก/ผิด และปุ่มกลับ/รีเฟรชตามฟังก์ชันที่ทำจริง
- ตรวจว่าแหล่งสารตัวอย่างไม่ถูกนำเสนอเป็นผลตรวจแม่น้ำ และสรุปไม่ตัดสินผู้ต้องสงสัย
- รัน pnpm test, pnpm typecheck, pnpm build:demo หลังติดตั้งด้วย lockfile; หากแก้ full stack ให้ทดสอบส่วนที่เกี่ยวข้องเพิ่ม
- ทดลองบนคอมและ iPad จริงที่ใช้สาธิต หากไม่ได้ทดลองให้ระบุว่าไม่ตรวจ
- เกณฑ์เสร็จ: เส้นทางที่ระบุเล่นจบได้ ไม่มีทางตัน แสดงผลและข้อจำกัดถูกต้อง เนื้อหาตรวจแล้ว และบันทึกผลตรวจใน state.md

## Phase 4 / 5
พักการทดลองกับผู้เรียน เผยแพร่และต่อยอดไว้ตามคำสั่งปัจจุบัน; ไม่ถือว่ามีผลทดลองหรือ deployment ใหม่จากเอกสารนี้

## บทบาท
- เจ้าของโครงการ/ครู: ยืนยันเนื้อเรื่อง คำถาม ชื่อ ภาพ ตรวจเคมี และเลือกอุปกรณ์/เวลาที่สาธิต
- ผู้พัฒนา: ตรวจ baseline, สร้างและเชื่อมแต่ละหน้า, ทดสอบเส้นทางและบันทึกข้อจำกัด
