# Google Sheets ที่อัปเดตผลนักเรียนเองอัตโนมัติ

Google Sheets จะดึงผลของนักเรียนทุกคนจากฐานข้อมูล (Supabase) เองทุก 10 นาที แล้วเขียนทับข้อมูลเดิม
ไม่ต้องเปิดคอมพิวเตอร์ทิ้งไว้ เพราะระบบทำงานบนเซิร์ฟเวอร์ของ Google
ถ้าต้องการไฟล์ Excel ให้กด **ไฟล์ → ดาวน์โหลด → Microsoft Excel (.xlsx)** ได้ทุกเมื่อ

ใช้เวลาตั้งค่าประมาณ 15 นาที ทำครั้งเดียว

## สิ่งที่ได้ในชีต

| แท็บ | เนื้อหา |
|---|---|
| สรุปรายคน | 1 แถวต่อนักเรียน 1 คน: สถานะ, Checkpoint ครั้งแรก, Checkpoint ล่าสุด, คะแนนที่นับ, ความคืบหน้า, แนวคิดที่ต้องทบทวน, ผล C01–C05 |
| รายครั้ง | 1 แถวต่อการทำ 1 ครั้ง: เวลาเริ่ม/จบ, Checkpoint, น้ำหนักครั้งที่ทำ, คะแนนที่นับ, ผล C01–C05 |
| ผลรายแนวคิด | ผลและเส้นทางของแต่ละแนวคิด รวมถึงผลครั้งแรกถูกหรือไม่ และเหตุผลของเส้นทาง |
| คำตอบทั้งหมด | ทุกคำตอบที่นักเรียนเลือกหรือพิมพ์ พร้อมถูก/ไม่ถูก และเวลาที่ตอบ |
| สถานะ | เวลาที่ดึงข้อมูลล่าสุด, สำเร็จหรือไม่, เปิดอัปเดตอัตโนมัติอยู่หรือไม่ |

- สูตรคะแนนเหมือนแดชบอร์ดครูบนเว็บทุกอย่าง: Checkpoint เต็ม 10, ครั้งที่ 1 = 100%, ครั้งที่ 2 = 90%, ครั้งที่ 3 = 80%, ครั้งต่อไป = 70%
- คะแนนครั้งแรกแยกไว้เป็นคอลัมน์ของตัวเองเสมอ
- ชีตแสดงข้อมูล **นักเรียนทุกห้อง** ในฐานข้อมูล จึงควรแชร์ให้เฉพาะผู้ดูแลหรือครูที่เกี่ยวข้อง
- ชีตเป็นสำเนาสำหรับอ่าน ถ้าแก้ตัวเลขในชีต รอบถัดไปจะถูกเขียนทับด้วยข้อมูลจริงจากฐานข้อมูล

## ขั้นที่ 1 — สร้างคีย์สำหรับชีตใน Supabase (5 นาที)

1. เข้า https://supabase.com/dashboard → เลือกโปรเจกต์ที่เว็บใช้อยู่ (ดูจากลิงก์ด้านบนว่ามีรหัสโปรเจกต์เดียวกับ Project URL ที่ตั้งใน Vercel; ถ้ารันผิดโปรเจกต์ ชีตจะขึ้นว่า "ยังไม่ได้รัน SQL")
2. เมนูซ้าย **SQL Editor** → กด **+ New query**
3. เปิดไฟล์ `supabase/migrations/20261104000000_sheet_export.sql` บน GitHub → กด **Copy raw file** → วางลงในช่อง SQL Editor
4. กด **Run**
5. ด้านล่างจะมีตารางผลลัพธ์ช่อง `export_key` (ตัวอักษรยาว 64 ตัว) **คัดลอกเก็บไว้ทันที** เพราะจะแสดงแค่ครั้งนี้ครั้งเดียว
6. เมนูซ้าย **Project Settings → API** (หรือ **API Keys**) คัดลอก 2 ค่านี้ไว้ด้วย
   - **Project URL** เช่น `https://xxxx.supabase.co`
   - คีย์ **anon public** อยู่ในแท็บ **Legacy API keys** ขึ้นต้นด้วย `eyJ` (คีย์เดียวกับที่ตั้งใน Vercel)

> ห้ามใช้คีย์ **service_role** หรือ secret (`sb_secret_…`) กับชีตนี้ ไม่จำเป็นต้องใช้ และห้ามส่งคีย์ใด ๆ ทางแชตหรืออีเมล
> ถ้าคีย์ secret หลุด ให้ลบทิ้งที่ **Project Settings → API Keys → Secret keys** ทันที

ถ้าคีย์หลุดหรือลืม ให้รันไฟล์ SQL เดิมซ้ำ จะได้คีย์ใหม่ และคีย์เก่าจะใช้ไม่ได้ทันที

## ขั้นที่ 2 — สร้าง Google Sheet และวางสคริปต์ (5 นาที)

1. สร้าง Google Sheet ใหม่ ตั้งชื่อเช่น "LearnLOOM ผลนักเรียน"
2. **ไฟล์ → การตั้งค่า** → เขตเวลา เลือก **(GMT+07:00) Bangkok** → บันทึก (เพื่อให้เวลาในชีตตรงกับเวลาไทย)
3. **ส่วนขยาย → Apps Script**
4. ลบโค้ดเดิมในไฟล์ `Code.gs` ทั้งหมด แล้ววางโค้ดจากไฟล์ `scripts/google-sheets/learnloom-sync.gs` บน GitHub (กด **Copy raw file**) → กด 💾 บันทึก
5. กลับไปที่ Google Sheet แล้วรีเฟรชหน้า 1 ครั้ง จะมีเมนู **LearnLOOM** เพิ่มขึ้นที่แถบเมนูด้านบน
6. **LearnLOOM → ตั้งค่าการเชื่อมต่อ** → ครั้งแรก Google จะขอสิทธิ์ (ดูขั้นที่ 3 ข้อ 2) → กล่องจะถามทีละค่า ให้วางแล้วกด ตกลง

| กล่องที่ | ค่าที่วาง |
|---|---|
| `SUPABASE_URL` | Project URL จากขั้นที่ 1 |
| `SUPABASE_ANON_KEY` | คีย์ anon public จากขั้นที่ 1 |
| `EXPORT_KEY` | `export_key` 64 ตัวจากขั้นที่ 1 |

ถ้าวางผิดรูปแบบหรือวางคีย์ secret กล่องจะเตือนและให้วางใหม่ ภายหลังถ้าต้องการเปลี่ยนแค่บางค่า ให้เว้นกล่องอื่นว่างไว้
คีย์ถูกเก็บใน Script properties ของสคริปต์ ไม่ได้อยู่ในตัวโค้ดหรือในชีต คนที่ได้สิทธิ์แค่ดูชีตจะไม่เห็นคีย์

## ขั้นที่ 3 — เปิดอัปเดตอัตโนมัติ (2 นาที)

1. **LearnLOOM → เปิดอัปเดตอัตโนมัติ (ทุก 10 นาที)**
2. ถ้า Google ขอสิทธิ์ ให้กด **ดำเนินการต่อ** → เลือกบัญชีของคุณ
   - ถ้าขึ้นว่า "Google ไม่ได้ยืนยันแอปนี้" ให้กด **ขั้นสูง → ไปที่ (ชื่อโปรเจ็กต์) (ไม่ปลอดภัย)** เพราะเป็นสคริปต์ที่คุณสร้างเอง
   - สิทธิ์ที่ขอคือ แก้ไขชีตนี้, เชื่อมต่อบริการภายนอก (Supabase) และตั้งเวลาทำงาน
3. รอสักครู่ แท็บต่าง ๆ จะขึ้นมา ดูแท็บ **สถานะ** ว่า "ผล" เป็น **สำเร็จ**

จากนั้นชีตจะอัปเดตเองทุก 10 นาที ถ้าต้องการข้อมูลทันทีให้กด **LearnLOOM → ดึงข้อมูลตอนนี้**
ถ้าต้องการหยุดให้กด **LearnLOOM → หยุดอัปเดตอัตโนมัติ**

## ถ้าแท็บสถานะขึ้นว่า "ไม่สำเร็จ"

| ข้อความ | วิธีแก้ |
|---|---|
| ยังตั้งค่าไม่ครบหรือรูปแบบผิด: … | กด **LearnLOOM → ตั้งค่าการเชื่อมต่อ** แล้ววางค่าที่ข้อความระบุชื่อไว้ใหม่ |
| EXPORT_KEY ไม่ถูกต้อง | คัดลอก `export_key` ผิด หรือรัน SQL ซ้ำแล้วได้คีย์ใหม่ ให้นำคีย์ล่าสุดไปใส่ |
| ยังไม่ได้รัน SQL sheet_export ใน Supabase | ทำขั้นที่ 1 |
| Supabase ตอบกลับ 401 | คีย์ anon ไม่ถูกต้อง หรือเป็นคีย์ของโปรเจกต์อื่น |

Google จะส่งอีเมลแจ้งเจ้าของสคริปต์ด้วยถ้ารอบอัตโนมัติล้มเหลว

## เรื่อง Excel

ไฟล์ .xlsx ที่ดาวน์โหลดเป็นภาพ ณ เวลาที่กดดาวน์โหลด ถ้าต้องการข้อมูลล่าสุดให้ดาวน์โหลดใหม่จากชีต
ไม่แนะนำ **ไฟล์ → แชร์ → เผยแพร่ไปยังเว็บ** เพื่อให้ Excel ดึงข้อมูลเอง เพราะ **ใครก็ได้ที่มีลิงก์** จะเปิดอ่านข้อมูลนักเรียนได้
